# Changelog

## 1.6.0 - 2026-10-10

- First public GitHub release with installation, privacy, troubleshooting, and contribution documentation.
- Recheck video cards when YouTube updates their metadata or reuses them for different videos.
- Keep full-length videos visible when a mixed section contains Shorts.
- Prevent stale filter work from overriding newer settings or pause state.
- Apply handle-based channel exceptions on channel video grids that omit individual channel links.
- Improve current-channel detection and popup input accessibility.
- Add DOM regression tests, continuous integration, and versioned release archives with checksums.

## 1.5.1 - 2026-09-26

- Support abbreviated publication dates such as `5d ago`, `2w ago`, and `1mo ago`.
- Prefer full publication accessibility labels when available.
- Leave unrecognized dates visible instead of treating them as old videos.

## 1.5.0 - 2026-09-26

- Add persistent pause/start controls and popup channel exception management.
- Limit age filtering to individual video cards.

## 1.4.4

- Support additional Shorts shelf and lockup layouts.
- Retain Manifest V3 and optional popup-controlled diagnostic overlays.
