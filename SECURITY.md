# Security Policy

## Supported versions

Security fixes are provided for the latest release. Update before reporting an issue that may already have been resolved.

## Reporting a vulnerability

Use GitHub's **Report a vulnerability** option in the repository's Security tab when available. Do not post exploit details, credentials, cookies, or personal browsing data in a public issue. If private reporting is unavailable, open an issue requesting a private reporting channel without including sensitive details.

Include the extension version, browser version, affected component, steps to reproduce, and expected impact. There is no guaranteed response time; this is a community-maintained project.
